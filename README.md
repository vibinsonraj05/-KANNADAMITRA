# KannadaMitra

An iPhone-inspired Kannada translation and learning app. Translate text into Kannada, use browser speech input, scan text from photos, save and revisit translations, and get a Gemini-generated path through the real lesson book.

## Project structure

- `app/` contains Next.js routes, layouts, global styles, and API route handlers under `app/api/`.
- `components/` contains shared interface and learning components used by multiple routes.
- `lib/` contains shared data, browser storage, database, language, and authentication logic.
- Root configuration files (`package.json`, `tsconfig.json`, and `next.config.js`) stay at the project root as expected by Next.js tooling.
- `.env.local` contains local secrets and is ignored by Git. `tsconfig.tsbuildinfo` is generated by TypeScript and ignored as well.

## Run locally

1. Use Node.js 20.19 or newer (required by MongoDB driver 7) and run `npm install`.
2. Create a MongoDB Atlas database user and database, then add its connection string as `MONGODB_URI` in `.env.local`. Allow your app host's IP in Atlas Network Access; URL-encode special characters in the database password.
3. Add `GEMINI_API_KEY` to `.env.local`. Translation uses stable `gemini-3.5-flash-lite` by default and falls back to `gemini-3.6-flash` during temporary service errors.
4. Run `npm run dev` and open http://localhost:3000. Keep both credentials server-side; never use a `NEXT_PUBLIC_` prefix.

The Next.js server exposes the Gemini endpoints and account endpoints. Atlas stores account profiles, password hashes and account-scoped translation history; history created on this device is migrated when History is opened. The local app automatically creates a session-signing key in Atlas, so no third credential is needed.

## App behavior

- Kannada is the fixed translation target. Text, camera and AI-path selectors share 28 source languages, including major Indian languages and common international languages. Tone/style, source, length, target, duplicate submission, rate, and provider errors are handled server-side.
- Camera OCR uses Gemini image understanding. It accepts JPG, PNG and WebP images up to 4 MB. Extracted text stays editable before translation.
- AI learning paths arrange existing book lessons according to language, level, goal, and daily minutes; each generated step must reference a valid lesson.
- Account profiles and translation history are stored in MongoDB Atlas. Saved entries, preferences, welcome state, generated path and learning progress are stored locally in the browser. Translation text and camera images are sent to Gemini when the user requests translation or scanning.
- Speech recognition and Kannada audio use device/browser capabilities where supported. Audio controls report or disable playback when no Kannada voice is installed. The app does not claim speech scoring.
- Sign-up and sign-in use server-side scrypt password hashes and HTTP-only, SameSite session cookies. Successful authentication opens the welcome transition. Database-backed accounts require a configured MongoDB Atlas URI.

## Verification

Run `npx tsc --noEmit` for the TypeScript check and `npm run build` for a production build. Next.js output-directory creation may fail with Windows `EPERM` in restricted workspaces; this is separate from Gemini credentials.
